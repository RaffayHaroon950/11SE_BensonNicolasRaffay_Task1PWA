# 11SE_BensonNicolasRaffay_Task1PWA

IMPORTANT NOTE: If you go to the GitHub pages link for our PWA, please first go to the Movies & Shows page using the nav bar. If clicking on a movie card brings you to a 404 error, please run our PWA on a local server instead by taking the following steps:

1. Download our repository to your machine.
2. Navigate to the folder of the repository in Command Prompt.
3. Type this into Command Prompt: "python -m http.server 8000".
4. Go to "http://localhost:8000" on your browser.

Our PWA should then be up and running.

Thank you, and enjoy!
